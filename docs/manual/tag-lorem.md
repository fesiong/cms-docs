# 生成随机文本

`lorem` 标签可以生成指定长度的随机文本内容。通常用于排版需要。

使用方法：

`{% lorem 数量 方法 random %}` 数量可以是按字数，也可以是按单词数计算，需要根据方法来决定。方法为以下几种中的一种：'w', 'p' or 'b'。random 为是否随机，默认不填，填写了 random 则随机。

### 示例代码

```twig
-----
{% lorem 10 w random %}
-----
{% lorem %}
-----
{% lorem 10 %}
-----
{% lorem 3 p %}
-----
{% lorem 100 w %}
-----
```
