# 过滤器：获取数字中指定位置的数字

## AICMS 模板中怎么获取数字中指定位置的数字？

`get_digit` 过滤器可以获取数字中指定位置的数字，位置从待获取的数字中倒数开始计算，从开始位置为 1。如果要获取的位置不存在，则返回整个数字。如果原数字是一个数字，则获取到的结果为该位置字符的 ASCII 值-48 得到的数字。

## 使用方法

`get_digit` 过滤器的使用方法：

```twig
{{ obj|get_digit:number }}
```

比如需要获取 `1234567890` 中获取倒数第 3 位的数字，则可以这么写：

```twig
{{ 1234567890|get_digit:3 }}
# 显示结果
8
```

## 示例演示

```twig
{{ 1234567890|get_digit:0 }}
{{ 1234567890|get_digit }}
{{ 1234567890|get_digit:2 }}
{{ 1234567890|get_digit:"4" }}
{{ 1234567890|get_digit:10 }}
{{ 1234567890|get_digit:15 }}
{{ "AICMS"|get_digit:2 }}
{{ "AICMS"|get_digit:2 }}
{{ "AI内容管理系统"|get_digit:2 }}
# 显示结果
1234567890
1234567890
9
7
1
1234567890
61
29
139
```
