# 过滤器：数字或字符串相加

## AICMS 模板中怎么将两个数字、字符串相加？

`add` 过滤器可以将怎么将两个数字、字符串相加。`add` 可以将整数、浮点数、字符串混合相加。也就是在你进行相加计算的时候，可以忽略他们的类型，在自动转换失败的时候，则会忽略相加的内容。

## 使用方法

`add` 过滤器的使用方法：

```twig
{{ obj|add:obj2 }}
```

比如将 `5` 加上 `2`，则可以这么写：

```twig
{{ 5|add:2 }}
# 显示结果
7
```

## 示例演示

```twig
{{ 5|add:2 }}
{{ 5|add:40 }}
{{ 5|add:nothing }}
{{ 5|add:"CMS" }}
{{ "AICMS"|add:"CMS" }}
{{ "AICMS"|add:"2" }}
# 显示结果
7
47
5
5CMS
AICMS
AICMS2
```
