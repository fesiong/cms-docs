# AICMS 文档

欢迎来到 **AICMS（AI内容管理系统）** 官方文档站。这里汇集了系统使用手册与完整的 API 接口文档，帮助你快速上手、部署与二次开发。

AICMS 是一款基于 Go 语言开发的开源内容管理系统，提供友好的后台管理、灵活的模板标签以及完整的 RESTful / GraphQL 接口。
