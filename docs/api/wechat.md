# 微信公众号服务地址接口

微信公众号服务器配置接口，用于接收和处理微信服务器发送的消息和事件。

## 注意事项

- 该接口采用GET和POST两种方法，用于微信服务器验证和消息接收
- 仅用于微信公众号服务器配置，不适用于普通API调用
- 需要在微信公众号后台配置此接口地址
- 需要实现微信官方的验证机制
- 该接口需要处理微信服务器发送的各类消息和事件

## 请求地址

```
{域名地址}/api/wechat
```

说明：`{域名地址}` 需要替换成你的域名地址，如 `https://www.aicms.com/api/wechat`

### 调用方法

该接口为微信公众号服务地址，参阅[接入指南](https://developers.weixin.qq.com/doc/offiaccount/Basic_Information/Access_Overview.html)

```bash
GET/POST
```

### 说明

该接口非普通访问接口，为微信公众号服务地址接口，在配置微信公众号的时候，填写到微信公众号官网 -> 开发-基本设置 中。
