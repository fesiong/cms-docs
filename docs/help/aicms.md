# 认识 AICMS

AI内容管理系统(AICMS)，是一款使用 GoLang 开发的企业站内容管理系统，它部署简单，软件安全，界面优雅，小巧，执行速度飞快，使用 AICMS 搭建的网站可以防止众多安全问题发生。AICMS 的设计对SEO友好，并且内置了大量企业站常用功能，对网站优化有很好的帮助提升，对企业管理网站一定程度上提供了办事效率，提高企业的竞争力。

AICMS 除了适合做企业站，也适合做营销型网站、企业官网、商品展示站点、政府网站、门户网站、个人博客等等各种类型的网站。AICMS 是什么，AICMS 是一个可以自由使用并开放源码的内容管理系统，你可以拿 AICMS 来搭建各种不违法的网站。

AICMS 支持 Django 模板引擎语法，该语法类似 blade 语法，可以非常容易上手模板制作。网站模式支持 自适应、代码适配、PC+mobile独立站点 模式，根据不用需求，可以选择适合自己的搭配方式来建站。

我们的追求：让天下都是安全的网站。

我们一直朝着网站安全的方向前进，让 AICMS 为你的网站安全护航。
